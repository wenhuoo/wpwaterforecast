# Western Port · 七天水况

在 Western Port 地图上点选位置，查看未来 168 小时的**浑浊风险趋势估算**。下载仓库后双击 `index.html` 即可打开，无需构建或 API 密钥。首页优先显示所选时刻和未来七天的风险等级；“影响因素”可展开查看风、外海涌浪、参考潮位、降雨及各自图表。

## 浑浊风险估算（实验性）

目前没有找到可用于这些任意地图点、逐小时预测的 Western Port 校准 NTU 模型或实时水质观测 API。因此页面给出的是**机制启发的相对风险等级**，不是 NTU、能见度或经现场验证的水质预报。等级为“较低 / 中等 / 较高”；小时图和每日卡片展示同一个等级趋势。

页面根据可用输入组合估算：10 m 风速（权重上限 35）、外海有效涌浪高度（20）、Stony Point 天文潮位的短时变化率（18）和当地六小时降雨（20）。缺项时按剩余权重重新归一化，至少需要两项输入；分值低于 22 为较低、22 至低于 48 为中等、48 及以上为较高。分值仅用于把预报驱动因素转成直观的相对等级，不是概率或物理单位。风、浪、潮、雨的权重、时间窗口和分级阈值均为初始启发式设定，尚未使用当地浊度数据拟合或验证。

解释等级时需留意：外海涌浪只作弱的入口扰动代理，不模拟 Flinders/两入口到所选点的传播；天文潮位变化率不等于潮流或底床切应力；逐点降雨不等于集水区径流或河流输沙；风速没有结合风向、浅滩暴露、实际水深或底质。河流负荷、悬沙沉降、絮凝、海草和有色溶解物也没有纳入数值评分。因此页面适合比较未来时段的相对风险，不适合据此判断实际 NTU、能见度、航行安全或是否适合捕捞。

要得到可信的 NTU 预测，需要同位置、同深度的连续浊度观测，以及同步的风浪流、潮位、降雨和河流流量/悬沙资料；在独立风暴、洪水与大小潮事件上校准并留出验证后，才适合报告数值预测及误差范围。

## 使用

- 点击地图即可选点，也可以拖动、缩放，或用键盘移动后按「选择地图中心」。初次打开从 Hastings 附近开始，之后记住上次选点。底图不用于判断航道或水深。
- 日期卡片从所标时刻起算连续 24 小时，显示最高风速和最高外海涌浪。切换七天或 24 小时视图，点图表或拖动滑块读取同一小时的风向、浪高、周期、来向、潮位和降雨。时间使用 `Australia/Melbourne`；CSV 同时保留 UTC。
- 点选后按坐标请求最近的天气模型网格；两个点落在同一网格上时可能得到相同天气。外海涌浪和 Stony Point 潮位对所有选点共用。

## 调研结论与模型边界

- **外海涌浪是西入口的重要候选因素。** 高度、周期、来向和水深共同影响扰底。入口变浑不意味着整个湾都会变浑；涨潮既可能输送颗粒，也可能带来更清的水。要验证内湾影响，先比较入口与目标点的同期流向、浊度及可解释时滞。
- **内湾还受本地过程控制。** 浅滩风区、实际水深、潮流和可动底泥影响再悬浮。槽滩交换、河口径流与岸蚀、沉降与絮凝影响峰值及恢复。藻类、碎屑和有色溶解物也会影响水的外观。
- **旧情景指数未校准。** 同一潮位变化率不能代替各地点潮流；统一沉降和换水公式不能外推到任意地图点位。EPA 月度历史表层样本不能替代新选点的实时浊度或验证小时峰值。
- **下一步验证。** 获取同地点同深度的高频浊度及波流资料，按完整、独立的风暴、洪水和大小潮事件留出验证，检查增加涌浪、入口输运和河流负荷后是否更准。

16 类机制、当地证据等级、各地验证重点和旧模型审计见[完整调研报告（2026-11-04）](research-cross-check-2026-11-04.md)。报告中的“当前网页”指改成地图前的版本。
